1. Tests de Supuestos (Validación previa indispensable) Objetivo: p ≥ 0.05
¡Regla de cátedra! Si los supuestos fallan (p < 0.05), el test paramétrico arroja conclusiones inválidas. En ese caso se utiliza la alternativa no paramétrica (basada en rangos).
Supuesto Test y Función Python Hipótesis Nula (H₀) Si p < 0.05 (Rechazo H₀) Si p ≥ 0.05 (No rechazo H₀)
Normalidad Shapiro-Wilk
stats.shapiro(data)		 Los datos provienen de una distribución normal. NO son normales
Descartar test t / ANOVA clásico.		 SÍ son normales
Se valida el supuesto paramétrico.
Normalidad
(Alternativa general)		 Kolmogorov-Smirnov
stats.kstest(data, 'norm')		 Los datos se ajustan a la distribución teórica. NO se ajustan
Menos potente que Shapiro en N moderado.		 SÍ se ajustan
Ajuste aceptable a la normal.
Homocedasticidad Test de Levene
stats.levene(g1, g2)		 Varianzas de los grupos son iguales (σ₁² = σ₂²). Heterocedasticidad
Varianzas estadísticamente distintas.		 Homocedasticidad
Varianzas homogéneas entre grupos.
Homocedasticidad
(Solo datos normales)		 Test de Bartlett
stats.bartlett(g1, g2)		 Las varianzas de los grupos son iguales. Varianzas distintas
Muy sensible ante no-normalidad.		 Varianzas iguales
Usar solo con normalidad probada.
Esfericidad
(k ≥ 3 dependientes)		 Test de Mauchly
pingouin.sphericity(...)		 Varianzas de las diferencias entre pares son iguales. No hay esfericidad
Aplicar corrección Greenhouse-Geisser.		 SÍ hay esfericidad
Se valida para ANOVA Medidas Repetidas.
2. Tests de Comparación: 1 Muestra y 2 Muestras Medias / Medianas
Diseño Muestral Test y Función Python Hipótesis Nula (H₀) Si p < 0.05 (Rechazo H₀) Si p ≥ 0.05 (No rechazo H₀)
1 Muestra
(Paramétrico)		 Test t (1 muestra)
stats.ttest_1samp(x, popmean=mu0)		 La media poblacional es igual a μ₀ (μ = μ₀). Media ≠ μ₀
Diferencia estadísticamente significativa.		 Media = μ₀
Compatible con el valor de referencia.
1 Muestra
(No paramétrico)		 Wilcoxon (1 muestra)
stats.wilcoxon(x - mu0)		 La mediana poblacional es igual a μ₀. Mediana ≠ μ₀
Diferencia significativa en la mediana.		 Mediana = μ₀
No se detecta desviación de μ₀.
2 Muestras Indep.
(Paramétrico estándar)		 Test t de Student
stats.ttest_ind(g1, g2, equal_var=True)		 Medias iguales (μ₁ = μ₂). Medias distintas (μ₁ ≠ μ₂)
Exige Normalidad y Homocedasticidad.		 Medias similares
No hay diferencia significativa.
2 Muestras Indep.
(Sin homocedasticidad)		 Test t de Welch
stats.ttest_ind(g1, g2, equal_var=False)		 Medias iguales (μ₁ = μ₂). Medias distintas
Ajusta grados de libertad por varianzas.		 Medias similares
No se rechaza igualdad de medias.
2 Muestras Indep.
(No paramétrico)		 Mann-Whitney U
stats.mannwhitneyu(g1, g2)		 Distribuciones iguales (P(X > Y) = 0.5). Distribuciones distintas
Si tienen igual forma, compara medianas.		 Sin diferencias
No hay dominancia estocástica.
2 Muestras Apareadas
(Paramétrico)		 Test t Apareado
stats.ttest_rel(antes, despues)		 Media de diferencias es cero (μ_dif = 0). Efecto significativo
Cambio medio estadísticamente distinto de 0.		 Sin efecto
El tratamiento no produjo cambio medio.
2 Muestras Apareadas
(No paramétrico)		 Wilcoxon Apareado
stats.wilcoxon(antes, despues)		 Mediana de diferencias es cero. Efecto significativo
Mediana de cambio difiere de 0.		 Sin efecto
No se detecta cambio en medianas.
3. Tests de Comparación: k ≥ 3 Muestras (Independientes y Dependientes) Multi-Grupo
Diseño Muestral Test y Función Python Hipótesis Nula (H₀) Si p < 0.05 (Rechazo H₀) Paso Siguiente (Post-Hoc)
k ≥ 3 Indep.
(Paramétrico)		 ANOVA 1 vía (One-Way)
stats.f_oneway(g1, g2, g3)		 Todas las medias son iguales (μ₁ = μ₂ = ... = μ_k). Al menos una media difiere Ejecutar Tukey HSD para determinar qué pares difieren.
k ≥ 3 Indep.
(No paramétrico)		 Test de Kruskal-Wallis
stats.kruskal(g1, g2, g3)		 Todas las distribuciones son iguales. Al menos un grupo difiere Ejecutar Post-hoc de Dunn con ajuste de Bonferroni.
k ≥ 3 Dependientes
(Medidas Repetidas)		 ANOVA Medidas Repetidas
statsmodels: AnovaRM(...)		 Medias en todos los momentos son iguales. Efecto del tiempo / condición Contrastes t-apareados post-hoc con ajuste de Bonferroni.
k ≥ 3 Dependientes
(No paramétrico)		 Test de Friedman
stats.friedmanchisquare(m1, m2, m3)		 Los rangos en todos los momentos son iguales. Al menos un momento difiere Post-hoc Wilcoxon apareado con corrección de Bonferroni.
4. Tests de Asociación e Independencia Relaciones
Tipo de Cruce Test y Función Python Hipótesis Nula (H₀) Si p < 0.05 (Rechazo H₀) Regla Crítica de Cátedra
Cualitativa vs Cualitativa Chi-cuadrado (χ²)
stats.chi2_contingency(tabla)		 Las variables son independientes. Variables ASOCIADAS
Existe dependencia estadística.		 Exige que las frecuencias esperadas sean ≥ 5 en al menos el 80% de las celdas.
Cuantitativa vs Cuantitativa
(Lineal)		 Correlación de Pearson
stats.pearsonr(x, y)		 No hay relación lineal (ρ = 0). Correlación lineal sig. Scatter con ratio 1:1. No mide relaciones no lineales y es sensible a outliers.
Cuantitativa vs Ordinal
(o no lineal)		 Correlación de Spearman
stats.spearmanr(x, y)		 No hay relación monótona (ρ_s = 0). Relación monótona sig. ¡Prohibido Pearson con ordinales! Spearman compara orden de rangos.
